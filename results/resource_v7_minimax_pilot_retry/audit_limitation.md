# 独立审计发现的输入记录缺陷

audit_resource_run 检查各组织签名的 input_hash 时失败：HTTP runner 记录的 messages 与随后追加消息共用可变列表。实际 HTTP 请求在调用时已序列化，但日志中的先前输入后来被修改。因此原报告的事件摘要签名有效，并不意味着每条输入日志真实反映发送时内容。

该现象与 V6 早期日志别名缺陷相同，新 HTTP runner 未复用冻结输入逻辑而再次引入。现已在发送和记录前做 JSON 深拷贝。保留原始报告，不重新签署或修饰历史日志；本次运行仍具有买方意愿、准备票据和执行确认，但不满足完整输入审计要求。不得声称整个独立审计通过。

另一个缺口是提交决定未签署时间，离线无法证明买方批准在决定时尚未过期。运行时有当前时间校验，历史日志不提供同等强度的事后证据。后续版本需要增加决定时间及对应检查。
